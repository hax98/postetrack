PosteItaliane SDA Tracking review fixes

Last updated: June 26, 2026.

This page documents the changes made for the Shopify App Store reviewer feedback.

1. Accurate and complete pricing information

The Shopify managed pricing configuration has been updated to remove the public free plan and remove the 14-day trial from all public paid plans.

  • Starter: $3/month, 200 shipments per month.
  • Growth: $20/month, 1000 shipments per month.
  • Scale: $40/month, 2000 shipments per month.

The public pricing information is also reflected in the app terms:

https://hax98.github.io/postetrack/terms.html

2. Theme app extension

The storefront widget is implemented as an official Shopify Theme App Extension. Merchants do not need to edit theme code or paste manual scripts.

  • Extension name: SDA Tracking Widget.
  • Extension handle: sda-tracking-widget.
  • Theme block file: extensions/tracking-widget/blocks/tracking.liquid.
  • Released Shopify app version: posteitaliane-sda-tracking-23.

Source reference:

https://github.com/hax98/poste-shopify-app/tree/main/extensions/tracking-widget

3. Onboarding instructions for theme app extension

The embedded app now includes setup instructions and a direct Theme Editor link.

  • Dashboard widget setup explains how to open Theme Editor, go to App embeds, enable SDA Tracking Widget, save, and preview an order page.
  • Settings page includes complete step-by-step instructions.
  • The app generates a Theme Editor deep link with activateAppId for the tracking app embed.

Source references:

Dashboard setup instructions

Settings setup instructions

Theme Editor deep link generation

4. Advanced notification fields

The Shopify Flow trigger now exposes split-shipment and predictive-delivery fields so merchants can build precise customer email automations from Shopify-owned tooling.

  • Split-shipment fields: isSplitShipment, splitShipmentIndex, splitShipmentCount, splitShipmentTrackings.
  • Predictive fields: predictedDeliveryAt, predictionConfidence, isLate, ageDays, baselineTransitDays.
  • Released Shopify app version: posteitaliane-sda-tracking-23.

Source reference:

https://github.com/hax98/poste-shopify-app/tree/main/extensions/tracking-status-flow-trigger

5. Data deletion on uninstall

The app uninstall webhook now deletes shop data, tracked orders, tracking events, sessions, API usage rows, and polling logs linked to the shop domain. The shop/redact webhook remains idempotent for follow-up Shopify privacy requests.

Source reference:

https://github.com/hax98/poste-shopify-app/blob/main/app/lib/gdpr.server.js
